# IP, License, and Transfer Notes

## Repository license
The repository includes a restrictive evaluation notice, not an OSI-approved open-source license. Inspection and local evaluation are permitted; production or commercial use, distribution, and derivative works require written permission from the copyright holder.

## Acquisition is separate from repository access
Publishing code or transferring repository administration does not automatically document a complete intellectual-property transfer. Buyer and seller should use a written agreement describing rights assigned or licensed, effective date, consideration, representations, exclusions, third-party components, and outstanding obligations. The buyer should verify authorship and rights for all included assets before closing.

## Third-party components
The application uses standard browser APIs and no bundled production runtime dependency. The optional development dependency @playwright/test retains its own license and notices.

## Exclusions
No customer contracts, subscriber list, paid users, real sales records, testimonials, proprietary connectors, domain ownership, production API keys, or recurring revenue are included or claimed. Seed products and workspace figures are fictional demo records.

## Before sale
1. Verify contributors and source ownership; remove any work whose rights are uncertain.
2. Review deployment and domain ownership separately from source control.
3. Decide whether the buyer receives an assignment, exclusive license, or non-exclusive commercial license.
4. Update the evaluation license only through the agreed written transfer process.
5. Test a clean deploy under the buyer's account.
