Honest product scope

Explore the product as it exists today.

MarginGuard is a local-first pricing prototype, not accounting or tax advice. Calculations use the assumptions entered in this browser. There is no cloud sync or verified business-performance data.

Only features explicitly implemented in the current app work. The scope notice above explains what is simulated or not connected.

The public repository contains the source and product notes. The demo is intended for evaluation, not as a promise of production readiness.
